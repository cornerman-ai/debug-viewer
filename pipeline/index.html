First time here? How to set up the data folder
  1. Get the Ambo folder onto this computer with Google Drive for Desktop, signed in with the account Ambo is shared with. If Ambo sits under Shared with me, add it to My Drive first: on drive.google.com, right-click Ambo → Organize → Add shortcut → My Drive.
  2. Find it on disk. Windows: File Explorer → Google Drive (usually G:) → My Drive → Ambo → data. Mac: Finder → Google Drive → My Drive → Ambo → data.
  3. Click Open Folder… and pick that data folder, in Chrome or Edge (other browsers cannot open folders). The page remembers it for next time.
The folder you pick has to look like this:
data/                            ← pick this folder
├─ pipeline_tests/               the results, from run_all.py
│  └─ <video>/                   one folder per video
│     ├─ punch_classification/
│     ├─ facing_angle/  …        one folder per stage
│     └─ rule_thresholds.json
├─ raw_videos/
│  └─ full_pipeline_test_videos/
│     └─ <video>.mp4             the footage
└─ skeleton_data/
   └─ full_pipeline_test_videos/
      └─ <video>_blazepose_full.npy   the stick figure
No Google Drive? A copy works just as well: the same three folders anywhere on disk. For one video, copy its folder from pipeline_tests, its .mp4 and its _blazepose_full.npy into the same places.
Running the backend? python combined_pipeline/pipeline_server.py, then open http://localhost:8766/: no folder to pick, and Upload video works.
